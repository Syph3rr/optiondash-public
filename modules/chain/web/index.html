Chain & screener

Price chart by TradingView (delayed data, needs an internet connection). Search any symbol in the chart's own box; it also follows the symbol you Load above. Indexes (SPX, NDX, RUT, VIX) are charted from a CFD that tracks them; XSP and DJX show the full-size index.

Each chain load holds about 50 market data lines while it snapshots, so it only runs when you press Load chain. IV is solved from the mark using the model, rate and yield above (IBKR's IV if it cannot be solved). The screener filters the loaded expiry; a multi-symbol scan, IV rank and term structure need data we do not have yet (see the README roadmap).
